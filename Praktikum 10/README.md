├── webgis-backend (Database & Routers)
├── webgis-frontend (React components & public data)
│   ├── public/data/detections.geojson (Hasil deteksi)
│   └── src/components/MapView.jsx (Logika Map)
├── main.py (Script Utama AI)
└── data (Penyimpanan citra GeoTIFF lokal)

## 📝 Cara Menjalankan

1. Jalankan proses AI: `python main.py`
2. Pindahkan hasil GeoJSON ke folder public frontend.
3. Jalankan web: `cd webgis-frontend && npm run dev`
